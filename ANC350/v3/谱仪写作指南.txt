======================================================================
光谱仪 (Spectrometer) 集成指南 (V3.1 架构)
======================================================================
本文档规定了将新光谱仪集成到 V3.1 应用程序所需的代码格式和架构要求。
您必须为光谱仪提供“三层”代码：驱动层、引擎层和视图层。

---
第 1 部分：驱动层 (Driver Layer) 写作要求
---
您必须在项目根目录创建以下三个文件。

文件 1: i_spectrometer.py (接口合同)
    - 必须使用 'abc' 模块定义一个抽象基类，命名为 'ISpectrometer'。
    - 必须定义以下抽象方法 (您可以增加，但不能减少):

    @abc.abstractmethod
    def connect(self):
        """连接到光谱仪硬件。"""
        pass

    @abc.abstractmethod
    def disconnect(self):
        """安全断开与光谱仪的连接。"""
        pass

    @abc.abstractmethod
    def set_parameters(self, integration_time_ms: float, averages: int):
        """
        设置采集参数。
        (注意: 引擎将从 GUI 获取这些值并传递给此函数)
        """
        pass

    @abc.abstractmethod
    def acquire_data(self) -> tuple:
        """
        执行一次采集并返回数据。
        
        [!! 关键格式要求 !!]
        返回: 必须是一个包含两个 numpy 数组的元组 (tuple):
               (wavelength_array, intensity_array)
        
        即使采集失败，也应抛出异常，而不是返回 None。
        """
        pass

文件 2: real_spectrometer.py (真实驱动)
    - 必须 `from i_spectrometer import ISpectrometer`。
    - 必须创建一个 `class RealSpectrometer(ISpectrometer):`。
    - 必须实现 `connect`, `disconnect`, `set_parameters` 和 `acquire_data`。
    - `acquire_data` 的返回值必须严格遵守 `(wavelength_array, intensity_array)` 格式。

文件 3: mock_spectrometer.py (模拟驱动)
    - 必须 `from i_spectrometer import ISpectrometer`。
    - 必须创建一个 `class MockSpectrometer(ISpectrometer):`。
    - 必须实现所有相同的方法。
    - `connect` 和 `disconnect` 应只包含 `print` 语句。
    - `set_parameters` 应使用 `time.sleep(integration_time_ms / 1000.0)` 来模拟采集时间。
    - `acquire_data` 必须返回与真实驱动 *格式完全相同* 的模拟数据（例如，使用 `numpy.linspace` 和 `numpy.sin` 生成假的波长和强度数组）。


---
第 2 部分：视图层 (GUI Plugin) 写作要求
---
您必须在 'gui_plugins/' 文件夹中创建一个新文件。

文件: gui_plugins/spectrometer_widget.py
    - 必须 `import tkinter as tk` 和 `from tkinter import ttk`。
    - 必须提供一个函数：`create_spec_frame(parent, app)`。
    
    此函数的目标:
    1.  在 'parent' (即 main_frame) 上创建一个新的 `ttk.LabelFrame`，用于容纳光谱仪控件。
    2.  创建所有 GUI 控件 (例如 "连接光谱仪" 按钮, "积分时间" 输入框, "平均次数" 输入框)。
    
    [!! 关键集成要求 !!]
    3.  需要被 `main_app.py` 访问的控件，必须附加到 'app' 实例上。
        示例:
        app.spec_connect_button = ttk.Button(spec_frame, text="连接光谱仪")
        app.spec_connect_button.pack()
        
        app.spec_int_time_entry = ttk.Entry(spec_frame)
        app.spec_int_time_entry.pack()

    4.  按钮的 'command' 必须绑定到将在 `main_app.py` 中创建的新回调函数。
        示例:
        app.spec_connect_button.config(command=app.handle_connect_spectrometer)


---
第 3 部分：引擎层 (Engine) 集成指南
---
您必须修改 'scan_engine.py' 以使其“知道”光谱仪的存在。

文件: scan_engine.py

1.  顶部 Imports:
    - 添加 `from i_spectrometer import ISpectrometer`
    - 添加 `from real_spectrometer import RealSpectrometer`
    - 添加 `from mock_spectrometer import MockSpectrometer`

2.  `__init__` 方法:
    - 在 ANC350 的状态变量旁边，添加光谱仪的状态变量:
        self.spectrometer: ISpectrometer = None
        self.is_spec_connected = False

3.  新的公共方法 (供 GUI 调用):
    - 创建 `connect_spectrometer(self, params: dict)`。
    - 此方法必须:
        a.  从 `params` 字典中获取 'integration_time' 和 'averages'。
        b.  启动一个新的私有线程 `_connect_spec_thread` 并将参数传递给它。
    - 创建 `disconnect_spectrometer(self)`。
    - 此方法必须启动 `_disconnect_spec_thread`。

4.  新的私有线程:
    - 创建 `_connect_spec_thread(self, int_time, avgs)`:
        a.  调用 `create_spectrometer_controller()` (您需要创建这个函数，模仿 `create_controller`)。
        b.  调用 `self.spectrometer.connect()`。
        c.  调用 `self.spectrometer.set_parameters(int_time, avgs)`。
        d.  如果成功, `self.is_spec_connected = True`。
        e.  向 GUI 发送新消息: `self.gui_queue.put(("connect_spec_success", None))`。
        f.  如果失败, `self.gui_queue.put(("connect_spec_fail", e))`。
    - 创建 `_disconnect_spec_thread(self)`:
        a.  调用 `self.spectrometer.disconnect()`。
        b.  `self.is_spec_connected = False`。
        c.  `self.gui_queue.put(("disconnect_spec_success", None))`。

5.  修改 `_start_scan_thread` (核心扫描循环):
    - 找到 `self.scanner.set_voltage(voltage)` 和随后的 `settle_time` 等待。
    - 在 *等待结束* 之后，*采集数据* 之前，添加以下逻辑：
        
        spec_data_to_send = (None, None) # 默认空数据
        if self.is_spec_connected and not self.stop_requested:
            try:
                # --- [新] 采集光谱 ---
                spec_data = self.spectrometer.acquire_data()
                spec_data_to_send = spec_data
            except Exception as e:
                # 采集失败，立即停止扫描
                self.gui_queue.put(("scan_error", f"光谱仪采集失败: {e}"))
                break # 退出 while 循环

    - 找到 `self.gui_queue.put(("plot_data", (i, voltage)))`。
    - [!! 关键修改 !!] 将其修改为包含光谱仪数据：
        
        self.gui_queue.put(("plot_data", (i, voltage, spec_data_to_send)))

6.  修改 `_shutdown_worker` (安全关闭):
    - 在断开 ANC350 的逻辑旁边，添加断开光谱仪的逻辑:
        
        if self.is_spec_connected and self.spectrometer:
            print("[Engine] 正在断开光谱仪...")
            self.spectrometer.disconnect()
            self.is_spec_connected = False

第 4 部分：视图层 (Main App) 集成指南
---
您必须修改 'main_app.py' 来加载新插件并处理新数据。

文件: main_app.py

1.  顶部 Imports:
    - 添加 `import gui_plugins.spectrometer_widget as spec_gui`

2.  `__init__` 方法:
    - 添加 `self.is_spec_connected_state = False`

3.  修改 `_create_widgets`:
    - 在 `anc_plugin_frame.pack(...)` 下方，添加新行来加载光谱仪插件:
        spec_plugin_frame = spec_gui.create_spec_frame(main_frame, self)
        spec_plugin_frame.pack(fill=tk.X, expand=False, pady=5)
    
    - [!! 关键修改 !!] 修改 Matplotlib 绘图区以支持双图:
      - 删除: `self.ax = self.fig.add_subplot(111)`
      - 替换为:
        self.ax_voltage = self.fig.add_subplot(2, 1, 1) # (2行, 1列, 第1个)
        self.ax_spectrum = self.fig.add_subplot(2, 1, 2) # (2行, 1列, 第2个)
        self.fig.tight_layout() # 防止图表重叠

4.  修改 `_init_plot`:
    - 此函数现在必须初始化 *两个* 图表。
    - 对 `self.ax_voltage` (上半图) 进行设置 (标题, 标签, `self.line_voltage, = ...`)。
    - 对 `self.ax_spectrum` (下半图) 进行设置 (标题, 标签, `self.line_spectrum, = ...`)。
    - 确保 `self.canvas.draw()` 在最后被调用。

5.  新的回调函数 (响应 GUI):
    - 创建 `handle_connect_spectrometer(self)`:
        a.  此函数应检查 `self.is_spec_connected_state` (是连接还是断开)。
        b.  如果是连接：从 `app.spec_int_time_entry.get()` 等控件读取参数。
        c.  将参数打包成 `params` 字典。
        d.  调用 `self.engine.connect_spectrometer(params)`。
        e.  如果是断开：调用 `self.engine.disconnect_spectrometer()`。
        f.  禁用/启用 `app.spec_connect_button` 等控件。

6.  修改 `periodic_queue_check` (处理引擎消息):
    - 添加新的 `elif` 块来处理来自引擎的新消息:
        
        elif msg_type == "connect_spec_success":
            self.is_spec_connected_state = True
            # (更新 GUI 按钮状态, 更新状态栏)
            self._update_status("光谱仪连接成功。")
            
        elif msg_type == "connect_spec_fail":
            self.is_spec_connected_state = False
            # (处理错误, 弹窗)
            self._handle_scan_error(data) # 可以复用
            
        elif msg_type == "disconnect_spec_success":
            self.is_spec_connected_state = False
            # (更新 GUI 按钮状态, 更新状态栏)
            self._update_status("光谱仪已断开。")

    - [!! 关键修改 !!] 修改 `"plot_data"` 处理器:
        
        elif msg_type == "plot_data":
            # 1. 解包新格式
            i, voltage, spec_data = data
            
            # 2. 更新电压图
            self._update_voltage_plot(i, voltage) # (将旧的 _update_plot 重命名)
            
            # 3. 更新光谱图
            if spec_data[0] is not None:
                self._update_spectrum_plot(spec_data)
            
            # 4. (重要) 只需调用一次 draw_idle
            self.canvas.draw_idle()

7.  新的/重命名的绘图函数:
    - 将 `_update_plot` 重命名为 `_update_voltage_plot(self, x, y)`。
    - 创建 `_update_spectrum_plot(self, spec_data)`:
        a.  `wl_data, int_data = spec_data`
        b.  `self.line_spectrum.set_data(wl_data, int_data)`
        c.  `self.ax_spectrum.relim()`
        d.  `self.ax_spectrum.autoscale_view(True, True, True)`

======================================================================
附录：项目环境与依赖 (V3.1)
======================================================================
[cite_start]本节内容基于 'readme.txt' (V1.9) [cite: 1, 2, 3, 4, 5, 6, 7]，用于定义项目所需的技术栈。

1. Python 库 (软件依赖)
本项目依赖以下核心 Python 库：
* [cite_start]`numpy`: 用于 `linspace` 生成扫描点序列，以及处理光谱数据数组。 [cite: 5]
* [cite_start]`matplotlib`: 用于在 GUI 中实时绘制电压和光谱图表。 [cite: 5]
* [cite_start]`ttkthemes`: (可选) 用于 "arc" GUI 风格，使界面更美观。 [cite: 5]
* `PyVISA`: (如果您选择) 用于 PyVISA/SCPI 协议的仪器（如光谱仪）通信。
* [cite_start]`ctypes`: (Python 内置) 已用于 `real_scanner.py` [cite: 4]，用于加载 `.dll` 文件。

2. 硬件与二进制文件 (硬件依赖)
* **ANC350 控制器**:
    * [cite_start]`anc350v4.dll`: 主库。 [cite: 5, 6]
    * [cite_start]`libusb0.dll`: `anc350v4.dll` 的 USB 依赖库。 [cite: 5, 6]
* **新光谱仪**:
    * (如果需要) 制造商提供的任何 `.dll` 或驱动程序。
    * (如果需要) NI-VISA 或 Keysight VISA 等底层 VISA 驱动。

3. 如何运行 (当前 V3.1 架构)

A. 离线开发 (MOCK 模式)
1.  确保已安装 `numpy`, `matplotlib`, `ttkthemes`。
2.  打开 `main_app.py`。
3.  [cite_start]设置 `USE_MOCK = True`。 (这将激活 `mock_scanner.py`) [cite: 5]
4.  (在 `scan_engine.py` 中) 确保您的 `create_spectrometer_controller` 逻辑也尊重 `USE_MOCK` 标志，以激活 `mock_spectrometer.py`。
5.  [cite_start]运行 `python main_app.py`。 [cite: 5]

B. 在线部署 (REAL 模式)
1.  [cite_start]在实验电脑上安装所有必要的硬件驱动程序 (ANC350 和 光谱仪)。 [cite: 6]
2.  将所有 `.py` 文件和 `gui_plugins` 文件夹放在同一目录。
3.  [cite_start]**将 `anc350v4.dll` 和 `libusb0.dll` (以及光谱仪所需的任何 DLL) 复制到该文件夹中 (与 `main_app.py` 同级)。** [cite: 6]
4.  打开 `main_app.py`。
5.  [cite_start]设置 `USE_MOCK = False`。 [cite: 6]
6.  [cite_start]运行 `python main_app.py`。 [cite: 6]
